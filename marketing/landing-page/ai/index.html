Use GoThere in Claude, ChatGPT and other AI assistants

GoThere runs an MCP server, so your AI assistant can look up visa requirements, move checklists, recent rule changes and citizenship by descent answers from the same verified data as this site. Every figure comes with its official source and the date it was checked.

Server address: https://getgothere.app/mcp

Set it up

Claude

  1. In Claude (web or desktop), open Settings, then Connectors.
  2. Choose Add custom connector, name it GoThere, and paste the server address.
  3. No sign in needed. Custom connectors depend on your Claude plan.

Claude Code

claude mcp add --transport http gothere https://getgothere.app/mcp

Cursor

Add to ~/.cursor/mcp.json:

{
  "mcpServers": {
    "gothere": { "url": "https://getgothere.app/mcp" }
  }
}

VS Code

Add to .vscode/mcp.json:

{
  "servers": {
    "gothere": { "type": "http", "url": "https://getgothere.app/mcp" }
  }
}

ChatGPT

A listing in the ChatGPT app directory is on the way. If your ChatGPT plan includes developer mode, you can already add the server address as a custom connector there.

What it can answer

  • get_visa_options: Residence visas for Americans moving to Spain, Portugal, Ireland, Italy or Mexico: income needed, fees, processing time, years to residency and citizenship.
  • get_move_checklist: Step by step checklist for one visa, with fees and any recent rule changes.
  • get_rule_changes: Verified changes to visa rules, newest first, each with the old and new value.
  • check_descent_eligibility: Whether a parent or grandparent gives you Irish or Canadian citizenship by descent.
  • get_pathway_requirements: Documents, cost and timing for the Irish and Canadian descent routes.
  • list_pathways: Which citizenship by descent routes are covered, and which are planned.

Try asking

  • “How much income do I need for Portugal's D7 visa?”
  • “Walk me through applying for Spain's digital nomad visa.”
  • “What changed recently in Portugal's visa rules?”
  • “My grandmother was born in Cork. Can I get an Irish passport?”

Privacy and limits

  • No account or sign in. Nothing you ask is stored.
  • Answers come from fixed rules and sourced data, not from a model guessing, and the server says so plainly when a country is not covered.
  • Research, not legal advice. Confirm with the consulate or a qualified lawyer before you file.
  • Also listed in the official MCP Registry as app.getgothere/citizenship.
